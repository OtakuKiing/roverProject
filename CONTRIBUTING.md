# Contributions

## Files & Variables
 - File names use `kebab-case`
 - Functions use `camelCase`
 - Variables use `snake_Camel_Case`
 - Constants use `SCREAMING_SNAKE_CASE`

## Commits
Commit titles should be prefaced with a one of 4 verbs; `Create`, `Amend`, `Update`, or `Delete`.  
For example, `Amend README.md` would suggest that errors were fixed (such as incorrect info, typos, moving location, etc). Alternatively, `Update README.md` would suggest that new information was added.

## Comments
**ESSENTIAL!**: 1 tab indent = 2 spaces. Always convert from tabs to spaces for accessibility, especially within Python.  

Each file should be prefaced with a short multi-line comment which serves as a description.  
`/*  Description  */`

Header comments divide code into key features.  
`##  Header  ##` or `//  Header  //`
